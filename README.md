# biblioteca-devops-GabrielAbreu

Sistema de Biblioteca - DevOps

Repositório criado para as atividades da disciplina de Cloud Computing e DevOps Avançado da UniALFA.

O projeto utiliza como exemplo um sistema de biblioteca que precisa receber atualizações sem ficar indisponível por mais de 5 minutos.

Atividades

Atividade 1 - Plano de Deploy e Rollback

Planejamento da atualização do sistema, incluindo a estratégia de implantação, testes e procedimentos para voltar à versão anterior em caso de falhas.

Trabalho 6 - Estratégia de Entrega Contínua

Continuação do planejamento, incluindo o fluxo de entrega, critérios de aprovação, monitoramento e riscos da implantação.
